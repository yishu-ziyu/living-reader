# Living Reader 产品愿景与经济世界研究交接

本文记录本次会话原本准备讨论和研究的内容、用户已经明确确认的产品愿景，以及仍需下一轮确认的问题。
本文只是一份会话交接，不替代 `design.md`、`CONTEXT.md`、产品简报、Teable 或代码中的正式事实。
本次对话没有授权任何产品实现；现有产品合同、代码、原型和资产均未修改，Teable 仅用于记录 T052 研究合同与会话断点。

## 一眼看懂当前状态

```text
完整图书 HTML
      ↓
可追溯的中文阅读
      ↓
读者阅读 ↔ Agent 对话与持续记忆
      ↓
出现可通过改变条件探索的问题
      ↓
声音或颜色提示 → 读者自主决定是否进入经济世界
      ↓
改变条件 ↔ Agent / 可能的角色 ↔ 可见后果
      ↓
形成新理解并带回后续阅读
      └──────────────────────────────→ 继续同一段阅读旅程
```

当前已经确认的是这条连续循环的产品方向。
当前还没有确认具体世界配方、比赛版本覆盖范围、翻译与记忆实现边界，以及最终的游戏式呈现方案。

## 用户已经明确确认

### 1. 产品是一段连续的 AI 阅读旅程

产品不是让用户在“阅读”和“经济世界”之间二选一，而是让阅读、对话、记忆、世界探索和新理解组成同一段持续生长的旅程。
经济世界从当前书籍、当前阅读位置和读者真实提出的问题中生长出来，探索所得的新理解还要继续影响后面的阅读与对话。

### 2. 产品应该允许导入一本书

产品应该允许导入一本书，而不是只接入少数提前摘出的段落。
本次比赛实例导入的是完整的《国富论》HTML，而不是只有 PDF 36 和 PDF 45 对应的两个片段。
完整导入不等于每个章节都已经拥有经济世界配方，配方覆盖范围仍需单独研究和确认。

### 3. 外文书应先为国内读者翻译成中文

面向国内读者时，外文原著应先提供可读的中文译文，不能要求目标读者以英文原文作为主要阅读界面。
中文译文仍必须能追溯到原文、版本和稳定位置，使读者能够核对译文、引用和 Agent 的解释。
翻译所用版本、生成方式、人工复核强度和译文呈现方式尚未确认。

### 4. Agent 与读者保持持续的阅读关系

读者在阅读过程中可以持续与 Agent 对话，而不是只在世界出现前后调用一次工具。
Agent 应在整段阅读旅程中记住读者读过什么、讨论过什么、哪里困惑，以及形成过哪些想法。
这些记忆服务于后续理解、提问和世界邀请，但记忆的数据结构、保存期限、隐私边界和读者控制方式尚未确认。

### 5. 经济世界由读者问题触发，并由读者决定是否进入

当读者提出一个可以通过改变条件来探索的问题时，Agent 可以用特殊的声音或颜色提示，并说明可以进入一个经济世界亲自试一试。
读者明确选择进入后，系统才进入经济世界，不能自动跳转，也不能把世界当成打断阅读的强制流程。
声音和颜色提示的具体样式、无障碍替代以及重复邀请规则尚未确认。

### 6. 世界内部仍然延续 Agent 关系

进入世界后，读者继续与 Agent 互动，也可能与世界中的角色互动。
读者可以改变经济条件，观察角色、资源、关系和指标产生的后果，并由此获得新的理解。
新理解、修正和遗留问题应回到阅读旅程中，与相关原文和后续阅读保持联系。
角色能够说什么、能否自主行动以及 Agent 与角色如何分工尚未确认。

### 7. 经济世界不是单一场景的同义词

禁止把产品或体验称为 `针厂游戏`。
针厂只可能是《国富论》中的一个经济世界实例，不能代表完整产品，也不能被当作全书唯一模板。
游戏式呈现是有效方向，但它与“选择哪些经济机制形成世界”是两个需要分别研究和确认的问题。

## 本来准备继续讨论/研究

### A. 从《国富论》全书寻找适合进入经济世界的机制

原计划以《国富论》完整第一手文本为依据，通读并检索 Books I 至 V，定位适合通过改变条件来探索的段落、问题和机制。
研究不能从现有两段实现倒推全书结论，也不能用二手摘要代替原文证据。
每个候选都应保留 Book、Chapter、稳定原文链接、短引文和版本信息，并区分 Smith 明示、忠实推论与现代设计映射。
Lane A 在用户要求停止后没有完成，因此目前不能列出候选配方，也不能声称已经覆盖 Books I 至 V。

### B. 把合适机制整理为经过审阅的“预制菜”

原计划把可用机制整理为经过来源核对和产品审阅的经济世界配方，而不是让模型在每次阅读时从零发明一个世界。
每份配方至少应包含原文依据、触发问题、经济机制、参与者、资源、变量、可执行行动、可见后果、失败状态、适用限制和可复用的呈现需求。
Teable T052 还提出了稳定字段，包括 `recipe_id`、`source_locator`、`source_quote`、`claim_type`、`mechanism`、`actors`、`stocks`、`flows`、`actions`、`predicates`、`metrics`、`state_transitions`、`failure_modes`、`visual_grammar`、`parameters` 和 `reuse_examples`。
这些字段是当前研究合同，不代表用户已经批准最终配方格式、配方数量或全书覆盖要求。

### C. 决定游戏式世界如何近实时组合出来

原计划继续比较世界的游戏式呈现方式，并回答如何用预制场景、实体、动作、声音、动画和图片原语，在读者接受邀请后近实时组合出当前世界。
目标不是实时生成一整套游戏，也不是让模型任意生成代码、坐标、完整美术资产或未经审阅的经济规则。
需要单独确认最终视觉风格、交互密度、角色表现、镜头与布局、音效、移动端、无障碍、暂停、回放和回到原文的方式。

### D. 补齐长期产品边界与比赛切片

原计划继续澄清完整图书导入与翻译、Agent 阅读记忆、世界邀请、角色对话与行动权限、配方覆盖、比赛交付切片和长期产品边界。
这些问题彼此相关，但不能因为长期愿景已经明确，就默认比赛版本必须一次实现所有能力。
下一轮需要先恢复全书配方研究，再用少量具体候选帮助用户判断产品边界。

## 当前仓库与新愿景的差距

现有 [`design.md`](../../design.md)、[`CONTEXT.md`](../../CONTEXT.md)、[`docs/product-brief.md`](../product-brief.md) 和正式产品界面主要围绕 Book I Chapters I 至 III、两个 `SourceBlock`、`ReaderIdea`、`BookThought`、关系审阅以及世界出现前的 Gate 展开。
这些现有材料记录了来源核对、读者想法归属、确定性世界结果和返回证据等仍然有价值的约束。
它们还没有完整表达本次新确认的完整图书导入、中文优先阅读、跨阅读旅程的持续 Agent 关系，以及由读者问题触发并由读者自主接受的世界邀请循环。
本交接只记录这个当前差值，不提出完整重设计，也不擅自判定哪些现有合同应保留、修改或删除。
当本交接与现有正式文档表达不一致时，下一轮必须先让用户确认具体产品行为，再把决定写回对应的权威文档。
在正式文档完成协调前，任何 Agent 都不能仅凭本交接开始产品实现。

## 尚未确认，不能当成决定

- 比赛版本是否要求整本《国富论》全部完成中文翻译，以及翻译达到什么质量才算可交付，目前尚未确认。
- 比赛版本是否只需要少量经过审阅的经济世界配方，还是需要覆盖更多章节，目前尚未确认。
- 完整导入使用哪个《国富论》HTML 版本、如何处理章节结构、脚注、译文和原文对照，目前尚未确认。
- Agent 记忆保存哪些内容、保存多久、读者如何查看和删除，以及如何避免把 Agent 推断误记为读者想法，目前尚未确认。
- 哪些问题算“可以通过改变条件来探索”，由代码、配方、Agent 还是共同判断，目前尚未确认。
- 特殊声音和颜色提示的具体形式、频率、可关闭方式和无障碍替代，目前尚未确认。
- 读者接受邀请后，世界是直接加载已有配方、需要短暂共同配置，还是允许有限参数化，目前尚未确认。
- 世界角色是否只能解释当前状态，还是拥有有限行动权和持续记忆，目前尚未确认。
- 游戏式呈现的最终美术方向、交互方式、镜头、音效和角色表现，目前尚未确认。
- DOM、CSS 与 Web Animations、PixiJS 或其他渲染路径尚未获得用户批准，目前不能成为正式架构决定。
- 需要多少配方才能代表比赛切片，以及长期产品是否支持任意书籍导入，目前尚未确认。
- 现有 `ReaderIdea`、`BookThought`、关系审阅和 Gate 应如何进入新的连续循环，目前尚未确认。

## 未解决风险

- 如果先实现再协调权威文档，Agent 会继续沿用两段原文和单一世界的旧范围，导致新愿景再次被压缩。
- 如果把 Lane B 的临时建议当作决定，渲染技术会在世界配方和游戏式呈现尚未获批前反向限制产品。
- 如果在 Lane A 未完成时声称全书覆盖，候选机制和世界配方会缺少第一手原文证据。
- 如果完整中文翻译没有明确版本、质量和追溯方式，国内读者得到的便利可能以来源可信度为代价。
- 如果 Agent 记忆没有读者控制和归属边界，持续关系可能变成不可检查的长期记录。
- 如果角色对话和行动权限没有先定义，世界可能退化为角色聊天外壳，或让模型未经规则直接改变经济结果。
- 如果比赛范围不尽快收窄，完整导入、翻译、记忆、配方研究和游戏式呈现可能同时扩张而无法形成可演示闭环。
