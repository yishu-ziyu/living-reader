# 初赛交付约束

> 核验日期：2026-08-07  
> 来源：用户提供的赛事章程＋[MiXer AI 开发者平台](https://open.hirebox.cn/)当日前端表单与公开文案

## 必须满足

- 2026-08-10 22:00（Asia/Shanghai）前提交。
- 填写 Agent 名称、团队和联系信息、简介、使用方式。
- 提供无需本地环境的公网 HTTPS 原始体验链接。
- 上传不超过 2 MB 的 PNG/JPG/WEBP 头像。
- 上传不超过 100 MB 的源代码 ZIP。
- 源码接受静态评分，体验/后端接受动态评分。

## 对架构有决定性的平台文案

平台当日提交页明确显示：

- 可选填写“自建 MCP 接口地址”，要求公网 Streamable HTTP。
- 自建 MCP 验证通过可额外加 5 分。
- 若没有自建 MCP，动态评分仍需要可运行的 Agent 后端，否则动态分为 0。

因此本项目将“可部署的 Agent 后端＋自建 MCP”列为 MVP 必做，而不是赛后优化。

## 尚未完全公开的信息

登录后的最终用例集、性能阈值和详细评分 rubric 未全部出现在公开页面。因此工程上将实现自有的 API/MCP 合同测试与响应时间记录，但不伪称已通过主办方的未公开测试。
