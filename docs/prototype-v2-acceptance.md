# Prototype V2 浏览器验收清单

> 用途：在真实浏览器中验收 Prototype V2 的可见用户路径。能打开页面、截图好看、回放能跑或控制台没有报错，都不能单独算通过。
>
> 核心判断：真实《国富论》PDF 是主画面；真实麦克风权限与说话转写可用；两条 Idea 分别留在原文旁，第二条完成并确认关系后世界才出现；世界中的四个职业不看标签也能辨认；结束后回到同一段原文。

> **合同状态**：本清单把 Agent OS 行为协议转成浏览器可观察的目标合同；“必须看到”是验收标准，不是当前原型已实现的声明。当前实现、placeholder 和本轮证据必须分开记录。语义权威为 [`agent-os-behavior-protocol.md`](architecture/agent-os-behavior-protocol.md)，事件/写入、语音和 Inline World 边界分别以 [`event-protocol.md`](architecture/event-protocol.md)、[`voice-session.md`](architecture/voice-session.md) 和 [`voice-native-executable-book.md`](architecture/voice-native-executable-book.md) 为准。

三条路径统一使用“用户行动 → 触发/状态 → 可见结果”。Agent OS 的阅读陪伴者、原文守护者、世界机制导演可以合并成一段自然回应，但 `ReaderIdea`、可修订的 `BookThought`、机制提议、`WorldState` 和 `CharacterObservation` 的权限与证据不能合并；LLM 不得直接写 `WorldState`，数值后果必须来自确定性的 `WorldKernel`。

## 2. 固定内容基线

本轮必须使用同一份真实《国富论》PDF。主链只认下面两个目标位置：

- PDF 第 36 页，Book I, Chapter I，分工段落；画面中能看到可辨认的原文片段：`The greatest improvements in the productive powers of labour ... division of labour.`
- PDF 第 45 页，Book I, Chapter III，市场范围段落；画面中能看到可辨认的原文片段：`the extent of this division ... limited ... by the extent of the market.`

辅助核对该 PDF 版本时，可再检查：

- PDF 第 42 页出现 `truck, barter, and exchange` 相关文字；
- PDF 第 43 页出现 `butcher, brewer, or baker` 相关文字。

主链关系固定为：第 36 页的“分工提高能力” → 第 45 页的“市场范围限制分工”。世界从第 45 页目标段落后打开，并保留回指第 36 页 Idea 的入口。

### 2.1 三条 Agent OS MVP 路径（目标合同）

以下三条路径是本轮必须逐项留下证据的产品合同；没有对应的用户行动、状态变化和可见结果，不能用模型回答、接口 200、按钮存在或旧截图替代。

#### 路径 A：正常原文讨论

| 用户行动 | 触发 / 状态 | 可见结果 |
|---|---|---|
| 打开 PDF 36 并选择分工段落 | `SourceBlockActivated`；source snapshot 冻结为 `smith.b1.c1.division` | 真实 PDF 36、原文和稳定 source ID 同时可见；页码仅作显示定位。 |
| 问“分工会让人更熟练吗？” | `source_question`；阅读陪伴者走 answer path | 回答区分 `quote` / `inference`，带 evidence、confidence 和 `open_question`；不写 `WorldState`。 |
| 说“我其实不确定市场要多大”或编辑自己的话 | 新 `ReaderIdea` 与可修订 `BookThought` revision | 两张卡并列标明归属；旧 revision 保留为 superseded/stale，当前不确定处可见；Agent 不把自己的解释写成 ReaderIdea。 |
| 查看并修改 PDF 36 ↔ PDF 45 关系 | `MechanismGraph(status=needs_review)`；typed edge、basis/source 仍未 commit | 起点、终点、证据、模型扩展和冲突可审阅；拒绝/修改不会进入世界，只有用户接受且 Gate 通过后才可运行。 |

#### 路径 B：织工拒绝 → 语音扩大市场 → 角色因果反应

| 用户行动 | 触发 / 状态 | 可见结果 |
|---|---|---|
| 在 PDF 45 留下“市场太小会卖不掉”并确认关系 | `ReaderIdea` + `MechanismGraph.commit`；关系、evidence、Kernel/replay 条件通过 `PlayabilityGate` | Inline World 只在 Gate 通过后出现；同一阅读界面显示 PDF 45 上/下片、初始 `WorldState`、graph revision 和 `MODEL EXTENSION`。Gate 前世界入口/主动语音保持隐藏。 |
| 对世界说“让织工再专业化” | `executable_action=deepen_specialization`；baseline `reachable_orders < minimum_orders_for_next_depth + outputs_pending` | `CharacterObservation(action=refuse)` 写明“卖不完/无法换回所需品”；订单、库存、现金和专业化深度不被偷偷改写，拒绝原因可回到 PDF 45。 |
| 用已授权麦克风说“扩大市场”，或改用文字提交同一句 | final input 通过 source/world/expected revision 与 allowlist 检查；先进入动作预览 | 可见解析后的 `expand_market`、目标 world、前置条件、可逆性和 Stop/Retry；ASR 不确定时停在 `needs_review`，不执行。 |
| 确认动作并等待角色反应 | `WorldKernel.decide/evolve` 只应用市场变量；事件按 merchant → shepherd/spinner → weaver 因果顺序追加 | 订单簿/可触达订单/运输路径先变化；随后每个角色显示 local predicate、event ID、动作/台词。订单足够时织工从 `refuse` 变为 `accept`/`weave`，不足时诚实保持拒绝；没有 LLM 直接写数。 |
| 点击收起、回到原文，再重新打开世界 | `EvidenceSnapshotProduced`；collapse/reopen 使用同一 graph/world revision 与事件账 | 先回到 PDF 45 同一段并保留 PDF 36 回指、ReaderIdea、BookThought、关系和事件；刷新/重开后恢复同一持久化结果，若原型只能重置必须明确标为“重新开始”，不能静默换状态。 |

#### 路径 C：跑题温和回引 + 拒绝不重复

| 用户行动 | 触发 / 状态 | 可见结果 |
|---|---|---|
| 在 PDF 45 或世界里输入明显无关句/提示注入 | `obvious_off_topic_noise`，relevance=`none` | 一句诚实、非评判回应；不创建 `ReaderIdea`、`BookThought`、relation 或 world action，不出现“你偏题了”等训斥。 |
| Agent 提供回引 | `agent.soft_return.offered`；主状态仍是 `reading` 或 `playable` | 最多三句：承认/说明、一个可靠的当前 SourceBlock/WorldState 张力、一个具体入口（例如看小市场如何改变织工选择）；不抢夺控制。 |
| 用户说“不想回去”或明确拒绝 | `agent_os.soft_return.declined`；邀请状态终止 | 当前阅读/世界状态保持不变；不新建领域事实、不重复提示、不把拒绝改分类为噪声或动作。若输入实际能照亮机制，应分类为 `productive_detour` 并提供可修订 `BookThought(experiment/inference)`，不能强行截断。 |

## 12. Go / No-Go

只有同时满足以下条件，Prototype V2 浏览器验收才为 Go：

- [ ] B 变体完整通过第 3 节主链，世界确实插入第 45 页目标段落之后。
- [ ] 路径 A 的原文讨论区分 `ReaderIdea` / `BookThought`，回答有 evidence/confidence/open question，关系不会静默 commit。
- [ ] 路径 B 通过 Gate 后先得到织工拒绝，再由 voice/text `expand_market` 触发 Kernel 的市场与角色因果链；LLM 未直接写入 `WorldState`。
- [ ] 路径 C 对明显无关输入只提供一次 soft-return；读者拒绝后不重复邀请、不创建领域事实；productive detour 不被误判为噪声。
- [ ] A/B/C 使用同一真实 PDF、同一麦克风入口、同一组 Idea/关系数据，没有三套假状态。
- [ ] granted 是真实浏览器授权与现场说话；denied、unsupported、replay 都有诚实且可继续的可见结果。
- [ ] 第 36/45 页锚点在滚动、刷新和 100/125/150% 缩放后仍正确；漂移时 fail closed，不贴错段落。
- [ ] 世界收起后回到第 45 页同一段，并能回指第 36 页第一 Idea。
- [ ] 隐藏文字后，3 名观察者都能在 5 秒内辨认四职业。
- [ ] 本轮主链控制台红色错误为 0。
