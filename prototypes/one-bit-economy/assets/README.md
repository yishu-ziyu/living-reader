# Koboyo-derived raster assets

The PNG files in this directory were selected through the `koboyo-icons` MCP and converted from the public monochrome icon source into 1-bit raster sprites for this throwaway prototype.

Source library: <https://koboyo.com/icons>

The MCP reports that the icons are free for personal and commercial use without attribution, but the library or a substantial subset may not be redistributed as an icon set. These eight rasterized icons are embedded as a small part of the prototype rather than redistributed as a library.

Selected slugs:

- `baker-kneading-dough`
- `bread-dough-served`
- `coins`
- `factory-worker`
- `factory`
- `injunction`
- `market-stall`
- `wheat`
